# GeoHarmonic

Chris's Geo Tool Kit: Python desktop tools for subsurface interpretation on public data.

| Tool | Folder | Status |
|---|---|---|
| Seismic Interpretation (2D + 3D, RGT model in progress) | `tools/Seismic Interpretation Tool` | building |
| Well log correlation (Kingdom/GeoGraphix style) | `tools/Well Correlation Tool` | v0.4.0 |
| 2D mistie analysis | `tools/Mistie Tool` | working |

Windows: in a tool folder run `Install (run once).bat`, then the tool's `.bat`.
Work in progress lives on the `dev` branch; see `docs/RUNLOG.md` and `docs/PLAN.md`.
